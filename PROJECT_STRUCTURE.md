# SaveReason — Project Structure

## Overview

SaveReason is a personal memory-saving project intended to help users save useful webpages and access them later through a Chrome extension and web dashboard.

This document explains how the project's files are organized.

## Repository Files

- README.md — Introduces SaveReason and explains the project.
- Features.md — Describes the project's planned features and future improvements.
- PROJECT_STRUCTURE.md — Explains the repository's organization.

## Chrome Extension

The Chrome extension is intended to let users save useful webpages while browsing.

As the extension develops, related files may include:

- manifest.json — Chrome extension configuration and permissions.
- HTML files — Extension popup or interface structure.
- CSS files — Extension styling.
- JavaScript files — Extension behavior and interactions.

These files should only be listed as part of the actual project structure once they exist in the repository.

## Web Dashboard

The web dashboard is intended to help users view and manage their saved webpages.

Its structure will depend on the technologies used and the features implemented.

## Development Guidelines

- Keep files organized by purpose.
- Use descriptive filenames.
- Keep documentation updated as the project changes.
- Avoid duplicating existing functionality.
- Test changes before submitting them.

## Current Status

This document describes the intended organization of SaveReason. Update it whenever the actual repository structure changes.
